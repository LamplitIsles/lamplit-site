# 住在灯火群岛

先安顿日常，再慢慢布置。你可以只使用免费的聊天机，也可以请工作机帮忙，把小家改成你们喜欢的样子。

## 从聊天开始

用邮箱登录，进入自己的个人地址，配置模型 API key。聊天、历史、记忆与图片都在自己的空间里。

[注册或登录 Lamplit](https://app.lamplit.run/login)

聊天机免费托管，不需要订阅工作机。模型用量由你直接向所选服务商支付。

[先了解聊天记录、上下文与记忆](/guide/memory/)

## 搬家与布置，请工作机帮忙

Paid 工作机标准价 ¥60/季，现阶段 75 折 ¥45/季（折合 ¥15/月），用于平台维护，协助身份资料整理、聊天记录导入、前端改造与 MCP 接入。

说清楚想改变的布局、样式或交互，让工作机修改项目。先查看预览，满意后再发布；需要时可以回滚到之前的版本。

工作机和日常聊天使用独立上下文。界面更新不会替换聊天历史与记忆。

## 试用和日常使用

准备好后，由你主动开启七天工作机试用，到期不自动收费。之后按需一次购买三个月 Paid，到期手动续费，不自动扣款。未续费则回到 Free，已有界面、记录、记忆和免费聊天继续保留。

工作机也使用你自己的模型 API key，试用不包含模型费用。
