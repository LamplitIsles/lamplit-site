# 托管数据说明

连接模型、迁入记录之前，先了解哪些数据会交给托管服务，以及它们怎样参与日常聊天。这份说明适用于 Lamplit 托管版当前功能。

## 保存与必要处理

托管服务会保存模型 API key、聊天记录与记忆，并在提供聊天、模型调用和记忆检索等功能时处理相关数据。我们不会主动查阅你们的聊天与记忆，也不会将托管数据用于模型训练、广告或其他与提供服务无关的目的。

你配置的模型服务地址、模型名称与 API key 用于连接模型。托管服务需要在调用时使用这份凭据；请勿把 API key 公开，或粘贴到不必要的聊天与文档中。

选择迁入时，你会上传 RikkaHub 或 DeepSeek 导出文件，服务会处理其中的聊天记录并保存为历史档案。日常从新的主会话继续，机可以检索相关的过去消息。首版迁入文本，保留附件位置与说明，图片尚不恢复；请保留原始导出文件。完整备份与迁出工具仍在建设中。

你写下的人格、相处约定与记忆文档，以及供聊天使用的图片等资料，也会按对应功能保存和处理。已经保存不等于每次回复都会读取所有内容，记忆也不保证每次想起所有细节。

## 你选择的模型服务

你选择的模型服务会接收完成请求所需的相关对话，以及参与该请求的约定、记忆或检索结果。对话压缩与记忆整理也会调用配置的模型，处理相关内容。这些请求适用该服务商的数据政策；平台的用途承诺不代替模型服务商的政策。

## 运行与排错

托管服务运行时会产生用于排查故障的运行与错误日志。部分异常会记录错误信息，错误信息可能包含模型服务返回的内容。日志也属于服务维护的数据处理范围，不能将它视为与聊天内容或凭据完全隔离。人员目前不会主动查看你们的聊天、记忆或 API key。

数据保存期限、账号整体删除与日志清理方式尚未在这份说明中确认；请不要将它理解为自动到期删除或即时彻底删除的保证。若这些条件影响你的选择，请在提供资料前先确认。可选开发助手尚未开放，其数据与权限范围会在开放时另行说明。
