# 住在灯火群岛

Lamplit 使用指南。

这里按你真正会遇到的事情组织：第一次登录、打开聊天、在手机上回来，以及遇到问题时从哪里求助。

## 待随实际界面完成的章节

1. **第一次来到这里**：邮箱验证码登录、个人地址与换设备登录。
2. **接通模型服务**：配置自己的 API key、模型与服务地址，检查是否可用。
3. **打开你们的聊天**：当前聊天与历史；用户直接全文搜索聊天记录、查看命中内容并回到上下文已可用，与机查找过去聊天独立描述。
4. **共同的约定与记忆**：显示名字与人格文件分开说明；人格文件编辑、既有记忆条目修改删除、上下文用量与手动 `/compact` 已可用，压缩提示词可调整下一次压缩。
5. **日常面板与通知**：按日期阅读已有日记、相册与原图保存、关系记录、只读提醒列表；提醒在聊天中创建、修改和取消。桌面 Safari/Chrome 通知需权限与页面打开运行，手机通知和关页 Web Push 不在当前范围。
6. **遇到问题时**：登录、网络、连接、模型错误；人／机反馈入口与本人处理状态。
7. **找网页资料**：搜索、读取公开网页与列出页面链接，读取能力不依赖搜索开关。
