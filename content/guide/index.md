# 安家手记

从认识自建，到照看你们的小家。

第一次打开教程，看到 API、上下文、部署这些词，觉得陌生很正常。你可以先沿着入门路线走，也可以带着一个具体问题来，找到答案就回去继续聊天。

## 一 · 搬家之前

- **想给你们留一个自己的地方**：为什么考虑自建，能改变什么，需要照看什么。首稿见 before-moving.md。
- **从哪条路走**：手机客户端、自己部署和托管的区别；RikkaHub、Operit 等方案放在对应路线里介绍。
- **带上什么，再出发**：原有记录、重要约定、模型账号与设备准备；说明哪些能导入、哪些仍需整理，不许诺一键接续。

## 二 · 把第一盏灯点亮

- **认识 API key**：去哪里取得、填在哪里、为什么不能公开。
- **在自己的 Cloudflare 账户上安家**：从准备账号到第一次聊天，按真实部署结果编写。
- **把入口放到手机上**：PWA、添加到主屏幕、联网与重新连接。
- **这盏灯，一个月花多少**：模型费用、云资源用量与可选开发能力的规划价格与建设状态。

## 三 · 把日子好好收着

- **聊天记录、上下文与记忆**：首稿见 memory.md。
- **留一页共同的约定**：称呼、重要背景、相处边界与需要补充的记忆。
- **照片与小日记**：图片、Markdown，以及怎样查找先前留下的内容。
- **以后想换个住处**：迁出原则与实际支持进度；完整迁出工具仍在建设中，保留迁入迁出的所有权目标。

## 四 · 按你们的习惯布置

- **先把想法说清楚**：从背景、字号、消息布局等具体需要开始。
- **把修房子的事交给工作机**：聊天机委派的程序员如何与日常分工；Lamplit 工作机和自有 Pi、Codex、Claude Code 两条路径。
- **添一件顺手的工具**：工具调用、MCP、服务凭据与访问范围。
- **想听见声音的时候**：语音路线与设备条件；按后续核实结果展开。

本章区分通用知识与 Lamplit 当前能力；迁入、人格文件编辑与定制对话压缩已可用，用户直接全文搜索聊天记录、查看命中内容并回到上下文也已可用；Phase 1 建设中只剩 MCP 接入；可选开发助手属 Phase 2 建设中，不作为现有操作教程。基础整理不需要订阅工作机，当前免费托管、模型费用自付，开发能力规划价 ¥45 / 3个月（75折，计划常规价 ¥60 / 3个月），尚未开放购买。

## 五 · 照看小家

- 一直显示连接中，该看哪里。
- 模型没有回复，怎样判断是网络、配置还是额度问题。
- 找不到一段旧对话时，先检查什么。
- 更新前后，要留意哪些变化。

## 随手翻的词典与工具架

mindmap 中的上下文、压缩、缓存、token、工具调用与 MCP，按读者遇到的问题分别解释。模型章节保留 DeepSeek、MiniMax、MiMo、GLM、GPT、Grok、Gemini、Claude 的选题，具体费用与能力核实后再写。

React、Svelte、Pi、数据库、RAG、实时语音和原生移动开发放在进阶工具架；需要时再翻，不作为安家的入门门槛。Obsidian、FlickNote、Notion 等资料整理工具也放在这里，说明它们如何参与日常整理。
