# 安家手记

从认识自建，到照看你们的小家。

你可以先沿着入门路线走，也可以带着一个具体问题来，找到答案就回去继续聊天。陌生的词，我们在用到时慢慢解释。

## 搬家之前

想一起延续的日常里，有哪些东西最重要？先看看手边的设备、记录与时间，选一条适合你们的路。

[读「想给你们留一个自己的地方」](/guide/before-moving/)

## 把日子好好收着

记录保存在哪里，一次回复能读到什么，重要的约定怎样留给以后。弄清这些区别，整理起来会更从容。

[读「把日子好好收着」](/guide/memory/)

## 接下来，我们一起写

**把第一盏灯点亮**：模型 API key、自托管部署、手机入口，以及每月的费用。

**按你们的习惯布置**：界面、照片、工具与工作机，让工作机协助修改，先预览，再发布。

**照看小家**：一直连接中、模型没有回复、旧记录找不到时，可以按什么顺序排查。
