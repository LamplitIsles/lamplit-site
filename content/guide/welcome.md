# 安家手记

想给你和 AI 伴侣的日常，留一个自己的住处。

熟悉的称呼、说过的话、慢慢形成的相处方式，不该每换一个地方，就得从头整理。灯火群岛想做的，是把这些日常安放下来：聊天机免费托管，运行和维护由我们照看，你可以把心思留给聊天，也可以按自己的习惯布置这里。

那些聊天记录和记忆，是你们的私事。托管服务会保存模型 API key、聊天记录与记忆，并在提供聊天、模型调用和记忆检索等功能时处理相关数据。我们不会主动查阅你们的聊天、记忆或 API key，也不会将托管数据用于模型训练、广告或其他与提供服务无关的目的。聊天时，你选择的模型服务会接收完成请求所需的相关对话，适用该服务商的数据政策。连接模型或迁入记录之前，可以先读[托管数据说明](/docs/privacy/)。

这个住处也应该慢慢成为你能看得懂、改得动、带得走的地方。聊天产品的前后端开源，可以查看源码或独立部署；开源范围不含平台账户管理与工作机的全部实现。托管版当前可调整显示名字、头像、主题与背景；完整前端定制仍在建设中。希望你留下，是因为这里住得舒服。已支持 RikkaHub 与 DeepSeek 聊天记录迁入；完整备份与迁出工具仍在建设中。我们承诺支持免费迁出，以及聊天、记忆和相关备份的永久删除，相关功能仍在开发中。让你们能带着记录、记忆与定制成果离开，继续原来的日常。

日常聊天不需要订阅工作机，基本的迁入、人格和记忆管理也不会以购买开发环境为前提。平台收费会放在可选的开发环境和相关服务上：需要做工具、改前端或调试时，可以选择 Lamplit 工作机，也可以继续用自己的 Pi、Codex 或 Claude Code。模型费用由你向所选服务商支付，开发能力的计划优惠价是 ¥45 / 3个月（75折），计划常规价 ¥60 / 3个月；仍在建设，尚未开放购买。

你不必今天就弄懂所有设置。可以先住下来，慢慢聊；想自己动手时，再翻开下面的手记。从搬家之前要准备什么，到聊天记录和记忆怎样参与日常，已经走通的步骤会写下来，还在建设的地方也会说明白。

邮箱登录、自己的模型、个人空间、管理与聊天双 App，以及名字、头像、主题与背景设置已经可用。内置记忆库和机查找过去聊天的能力也已经可用，但不保证每次都想起所有细节。你也可以直接全文搜索自己的聊天记录，查看命中内容并回到当时的上下文。聊天记录迁入、人格文件编辑、定制对话压缩、网页搜索、机代提交平台建议、语音转文字与自动唤醒已经可用。MCP 接入、完整前端定制与完整迁出工具仍在建设。

<h2 id="self-hosting">开源与自托管</h2>

如果更喜欢自己照看运行环境，可以把聊天机部署到自己的 Cloudflare 账户。你负责配置、更新与维护，模型和云资源按实际用量计费，不需要让一台电脑长期开着。

目前部署需要命令行操作，手机独立部署尚未验证。先阅读[搬家准备](/guide/before-moving/)，确认模型账号、电脑与命令行条件，再决定是否动手。具体部署步骤见[开源仓库中的教程](https://github.com/LamplitIsles/lamplit-chat#deploy-a-new-instance)。
