# 安家手记

想给你和 AI 伴侣的日常，留一个自己的住处。

熟悉的称呼、说过的话、慢慢形成的相处方式，不该每换一个地方，就得从头整理。灯火群岛想做的，是把这些日常安放下来：聊天机免费托管，运行和维护由我们照看，你可以把心思留给聊天，也可以按自己的习惯布置这里。

那些聊天记录和记忆，是你们的私事。我们不会将它们用于模型训练。聊天时，你选择的模型服务仍需要处理相关对话，它的数据政策也需要你留意；这是平台和模型服务商各自要负责的事。

这个住处也应该是你能看得懂、改得动、带得走的。聊天机的前后端开源，查看源码、修改界面，或者部署到自己的环境，都有路可走。希望你留下，是因为这里住得舒服；想离开时，也能免费带上聊天、记忆和亲手布置的成果，继续原来的日常。迁入和完整迁出工具还在建设，免费迁入迁出是要走通的方向，进度也会写清楚。

日常聊天不需要订阅工作机，基本的迁入、人格和记忆管理也不会以购买开发环境为前提。平台收费会放在可选的开发环境和相关服务上：需要做工具、改前端或调试时，可以选择 Lamplit 工作机，也可以继续用自己的 Pi、Codex 或 Claude Code。模型费用由你向所选服务商支付，工作机的具体收费方案还在设计。

你不必今天就弄懂所有设置。可以先住下来，慢慢聊；想自己动手时，再翻开下面的手记。从搬家之前要准备什么，到聊天记录和记忆怎样参与日常，已经走通的步骤会写下来，还在建设的地方也会说明白。

## 接下来，我们一起写

**把第一盏灯点亮**：模型 API key、自托管部署、手机入口，以及每月的费用。

**按你们的习惯布置**：当前可以设置显示名字、头像、主题与背景。可选的 Lamplit 工作机与自有 Pi、Codex、Claude Code 集成仍在建设，目标是由聊天机委派开发，先预览，再发布。

**照看小家**：一直连接中、模型没有回复、旧记录找不到时，可以按什么顺序排查。

## 当前托管与建设进度

邮箱登录、自己的模型、个人空间、管理与聊天双 App，以及名字、头像、主题与背景设置已经可用。内置记忆库和机查找过去聊天的能力也已经可用，但不保证每次都想起所有细节。完整前端定制、迁入与完整迁出工具，以及其他添置能力仍在建设。

想先熟悉已有设置，可以[阅读使用指南](/docs/)；想知道接下来会添置什么，可以[查看建设图](/roadmap/)。

<h2 id="self-hosting">开源与自托管</h2>

如果更喜欢自己照看运行环境，可以把聊天机部署到自己的 Cloudflare 账户。你负责配置、更新与维护，模型和云资源按实际用量计费，不需要让一台电脑长期开着。

目前部署需要命令行操作，手机独立部署尚未验证。先阅读[搬家准备](/guide/before-moving/)，确认模型账号、电脑与命令行条件，再决定是否动手。具体部署步骤见[开源仓库中的教程](https://github.com/LamplitIsles/lamplit-chat#deploy-a-new-instance)。
