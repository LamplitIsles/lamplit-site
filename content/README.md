# 灯火群岛 · 内容编辑基准

本目录存放受版本控制的公开文章与内部编辑骨架。已登记文章在静态构建时渲染；根目录 `letter.md` 是作者原稿，保留原样。首页以 `src/routes/+page.svelte` 为准，不维护另一份过时营销草稿。

## 当前产品边界

依据 FlickNote Spec #2882、设计决定 #2881 与文案边界 Spec #2945，以实际可用体验记录状态。

- 当前可用：邮箱登录、自己的模型（BYOK）、个人空间、管理与聊天双 App（技术实现为 PWA）、显示名字/头像/主题/背景。
- 当前可用：内置记忆库、机查找过去聊天（现有 memory context 与 session_search）。对外不使用工具名，不保证永久记忆或自动回忆所有历史。
- 当前可用：RikkaHub 与 DeepSeek 聊天记录迁入、人格文件创建维护、定制对话压缩。
- Phase 1 建设中：用户直接全文搜索聊天记录并回到上下文、网页搜索、语音输入、自动唤醒、机代提交平台建议。
- Phase 2 建设中：聊天机委派开发助手，做工具、前端、调试与增强。Lamplit 工作机与自有 Pi、Codex、Claude Code 是两条可选集成路径，先工作机、后自有 Agent。建设中指平台集成，不指这些 Agent 工具本身不可用。
- 基础迁入、人格与记忆管理不需要订阅工作机，不放在付费开发助手之下。
- 当前免费托管，模型费用由用户向服务商支付；开发能力规划价为 ¥45 / 3个月（75折），计划常规价 ¥60 / 3个月，明确标注规划中、尚未开放购买；不编造试用、额度、自动付费或续费规则。
- 已支持 RikkaHub 与 DeepSeek 记录迁入，完整迁出工具仍在建设中；模板分享与更多连接仍属后续规划。聊天机完整前后端开源、自托管可用，云资源按实际用量计费。

后端检索不等于用户搜索界面交付，定制对话压缩仅影响下一次压缩，显示名字不等于人格文件配置。导出格式逐项适配，不许诺所有客户端格式或无损一键接续。远程 MCP 未核实，不列作已上线能力。旧 Phase 1B 营销完成基准已撤销，不以人为状态代替实际验收。

自动唤醒只表达机在合适的时候醒来主动联系，不承诺固定时间、渠道或后台运行。平台建议由机代为提交使用建议和问题，不改写为只有用户手动填表，不暗示默认上传私密聊天。两项均仅展示建设状态，不含新工具、权限或提交后端。

## 表达与视觉

首页主句：“让你和 AI 伴侣的日常，有一个自己的住处。”，主说明“免费托管，前后端开源*”，紧邻展示聊天机托管免费、模型费用自付与开源范围说明。开源仅指聊天产品前后端，不扩大到账户管理/工作机全部实现。核心理念是让聊天、记忆与定制成果属于用户。当前状态统一为“已支持 RikkaHub 与 DeepSeek 聊天记录迁入；完整备份与迁出工具仍在建设中”，免费迁出，以及聊天、记忆和相关备份的永久删除作为明确承诺，单独标注相关功能仍在开发中。主 CTA 为“登录”，指向 `https://app.lamplit.run/login`。对外使用“管理与聊天双 App”和“当前可调整显示名字、头像、主题与背景；完整前端定制仍在建设中”；开源入口标“开源仓库”。导航使用独立链接与真实布局间距，桌面靠右对齐正文右边界；移动端可换行。

固定雾蓝浅色，以 daisyUI 语义 token 统一：主色 #365c78、背景 #f3f6f8、白色表面、浅蓝 #e1ecf3、正文 #263747、次文 #617384。浅蓝表面使用更深正文色以保持对比。暖窗灯是品牌意象，使用 `static/images/home-island.png` 透明产品资产等比呈现，旧 SVG 已移除；Emoji 辅助；工程状态必须保留“建设中”文字。使用可用 Noto Sans SC 或系统 sans，不下载大字体，不依赖 Mac 专有字体。常用交互目标至少 44px，保留键盘焦点。

- 搬家叙事从同一位伴侣与共同生活的延续出发，不写成复制品或替代品，也不替读者裁定身份连续性。
- 尊重读者自己的称呼与关系理解，优先用“你们”“伴侣”，不指定性别或判定关系与意识。
- 温度来自具体细节。谈定制时具体说界面、约定、记忆或工具，不给按钮强加隐喻。
- 解释故障时区分模型、客户端、历史、记忆与平台，不把技术问题解释为关系变化。
- 不承诺永久记忆、永不宕机、搬家后相同体验或模型永不改变。
- 给伴侣的信只是问候，不要求绕过用户同意、访问权限或收集私密资料。
- 安家手记以连贯、像信的正文融入平台不将聊天/记忆用于训练、聊天前后端开源、免费聊天与基础能力、可选付费开发环境及自由迁入迁出原则；模型商数据处理责任另说。RikkaHub 与 DeepSeek 记录迁入已可用，完整迁出工具仍建设中，保留继续日常的目标，不保证无损接续。不要另设承诺清单或重复整套营销段落，不编造保存或删除细节。
- 旧站只作表达参考，不沿用 Docker/Core/Full、Hindsight、Keet 或旧许可证作为当前能力说明。

## 后续编辑与验证

先按真实界面补齐操作步骤、模型配置、自托管部署、手机入口和排错；语音、工具与进阶开发按实际核实结果展开。尚未写完的章节只登记选题，不伪装成操作教程，不新增博客或 CMS。

公开文案人工审阅，不加精确文案或源码形状测试。运行 `bun run check`、`bun run build`，在本地生产预览检查 390/1440/320、文章阅读、建设图展开与焦点。截图、核对记录放 `.scratch/`，不入 Git。部署另行授权，构建通过不代表已上线。

托管会保存模型 API key、聊天记录与记忆，并进行服务必要的处理。人员不主动查阅，托管数据不用于模型训练、广告或服务无关目的；模型商政策另说。运行日志可能记录异常信息，不承诺日志绝无私密数据。未核实的保存期限与整体删除机制不编造，当前说明入口为 `/docs/privacy/`。

首页所有权原句保留“让聊天、记忆与定制成果属于你们，能迁入，也能迁出”，下方明确完整迁出仍在开发中。永久删除承诺覆盖聊天、记忆及其备份，服务运行与错误日志不在范围内；定制资料的删除范围尚未确认，不扩大承诺。
